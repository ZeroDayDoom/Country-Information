# 🌍 Country Information

A lightweight web app that fetches and displays key facts about any country, powered by the [REST Countries API](https://restcountries.com/). Built with vanilla HTML, CSS, and JavaScript.

🔗 **Live demo:** [zerodaydoom.github.io/Country-Information](https://zerodaydoom.github.io/Country-Information/)

## Features

- 🔎 Search any country by name
- 🚩 National flag display
- 🏙️ Capital, continent, currency (code + name), languages, and population
- ⚠️ Friendly error messages for empty or invalid input

## Getting started

```bash
git clone https://github.com/ZeroDayDoom/Country-Information.git
cd Country-Information
```

Open `index.html` in your browser and search for any country — no build step or API key needed. The app calls the free [REST Countries API](https://restcountries.com/) directly.

## Project structure

```
Country-Information/
├── index.html   # page markup
├── style.css    # styling
└── script.js    # search logic + REST Countries API calls
```
